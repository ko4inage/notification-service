Сервис обработки сообщений из Kafka.

Для каждого топика отдельный Listener проверяет уникальность сообщения по key+value и сохраняет в соответствующую таблицу inbox. При дубликате - пропускает обработку

Для каждой таблицы inbox отдельный шедулер с заданным настраиваемым интервалом выбирает полученные сообщения для последующей обработки. Применяется паттерн Transactional Inbox
